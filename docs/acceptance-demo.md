# 验收演示与交付索引

## 本机演示

1. 双击项目根目录 `Start-WeKnora.cmd`，等待五个容器健康，打开 `http://127.0.0.1:5174`。
2. 使用本机已有账号进入模型管理，查看四个对话模型、两个向量模型及美元价格版本。
3. 打开知识库“验收示例（合成资料）”，查看已解析的 `acceptance-example.md`。材料包含座位数、开放时间和预约条件。
4. 在评测工作台查看“个人服务验收：2题合成资料”的完成任务，检查逐题回答、检索结果、耗时、用量与费用，再下载 JSON 或 CSV 导出文件。JSON（JavaScript Object Notation）保存结构化结果，CSV（Comma-Separated Values，逗号分隔值）用于表格分析。
5. 查看模型统计与调用账本。成功调用保留供应商用量、价格快照和实际费用；未确定费用保留对应状态。
6. 打开[扩展实测报告](reports/expanded-acceptance/README.md)，展示三套公开数据的质量检查、两个模型的回答质量、完整检索流程、跨批次页面生成缓存及浏览器证据。[持久化与故障实测](reports/final-acceptance/README.md)提供五次重启缓存对照、内容修改探测和取消恢复证据。
7. 展示[正常交付变更](https://github.com/Aokiuuz/WeKnora/pull/1)和[受控退化变更](https://github.com/Aokiuuz/WeKnora/pull/2)。后者保留检查失败及合并阻断证据，处于关闭状态。

现有评测记录可以直接查看。重新执行评测或发起问答会按所选供应商计费。

## 证据版本与边界

不同证据绑定不同源码版本，引用时不得互相替代：

| 证据 | 绑定提交 | 适用范围 |
| --- | --- | --- |
| 扩展实测（1,200 回答、200 检索、90 组 Wiki 配对） | `86436db4`（读者探针）、`d0535cdf`（检索 HTTP 任务执行） | 固定公开子集上的实测质量与费用 |
| 远端必需门禁通过 | `0e3fce68` | 该提交的冻结指标回归 |
| 外部本地候选验证 | `25cf5a95` 加当时工作树改动 | 本地日志记录基线与修复树；部分最终验证在 12 个未提交文件的状态执行，不能作为干净 25cf5a95 的结果 |
| 外部提交的远端验证 | `0fa806075232c75934c87477e46d1446febb8a8b`；CI 合成提交 `6a6b32c6bdf6d66e545c856825f22f6c6f16a2b5` | 两提交树 SHA 相同；远端日志和产物验证见主管审核记录 |
| 主管局部修复与隔离验证 | `76e11497b985118bf1a7c323c94a181ccbdf70bb` | 缓存告警脱敏、筛选请求失效与加载标志的回归；完整集成状态由最终交付索引登记 |
| Apple M4 工程复现 | `1776aa44` | 该提交的两轮独立运行，后续改动不在其范围 |
| 浏览器 12 项检查 | `db56f0d9` | 当次前端构建的界面行为 |

口径边界：确定性门禁精确比较冻结 golden 指标；真实检索质量另由 20 题固定语料的阈值下限守护，两个数据集约 50 题的小样本实测不能外推为模型整体检索排名。普通对话请求按最佳努力记账，数据库故障窗口内账本可能少于供应商实际调用；评测任务采用严格记账，记账失败即任务失败。嵌入缓存写入或命中事件记录失败不影响向量返回，但会以脱敏告警写入日志（仅条目数或固定状态、固定错误类别，不输出原始存储错误、租户标识、模型标识、原文、向量或凭据）。云解析费用未知保持 null；本地接口零费用不含硬件与电费。

界面行为补充：评测工作台应用新筛选条件时，先前打开的任务详情随之失效并被清空，空结果筛选显示空详情；进行中的详情与问题分页请求通过序列门校验；筛选同步释放加载标志，迟到响应被丢弃。

## 交付边界

公开报告包含脱敏汇总、回答、机器评分、配对结果与文件摘要。本机证据目录保存原始数据库、导出、收据、失败批次和预算文件，涉及账号及运行环境的数据按本地资料保管。

本轮人工评分暂不执行，字段保持空值。公开参考答案用于自动比对，模型辅助意见保留机器评分身份。无答案拒答准确性、公开数据的预训练重叠风险、完整仓库静态检查结果，以及 Apple M4 证据的具体源码范围见扩展实测报告。

## 导出契约备注

CSV 导出中 `run_status` 为整数编码，状态映射为：0 待执行（pending）、1 执行中（running）、2 成功（success）、3 失败（failed）、4 超时（timed_out）、5 中断（interrupted）、6 已取消（canceled）。JSON 导出的 `task.status` 使用同一编码。既有列与 `schema_version` 保持不变。
