# 实验方法与数据说明

系统交付包括持久评测工作台、固定指标回归、模型调用账本、模型与时间统计、持久化嵌入缓存、Wiki固定前缀和八引擎解析基线。下表列出各组实验的测量对象、统计分母与执行身份。

| 证据 | 测量与统计口径 |
|---|---|
| 工程验收 | 合成供应商和合成价格支撑可复现的接口、指标及账本验证；真实模型质量采用独立实验数据 |
| 当前前端 | 921项测试、34个中英文布局场景、5项实际按钮操作；源码及构建身份见versions.json |
| 完整后端 | 单命令验收绑定1cc446d64c10a3b56f86802cc22ffb1ecdb37272；当前集成差异为三个前端组件样式，模板与脚本字节一致 |
| 完整Go套件 | 9259通过、33跳过，执行版本54ee23b25bf5da95954a6808da80122e7461f6f3；后续受影响模块验证按各自版本登记 |
| 原文问答 | 600题×2模型，1200份回答；已观察的公开子集；EM/F1为机器词面指标，6份格式无效回答计零，人工评分字段为空 |
| Wiki | 三批各30对，共90对；共享供应商缓存造成配对相关；第三批中位耗时比1.178；令牌、费用和耗时分别统计 |
| 八引擎 | 同批100PDF×8，636成功、160错误、4空输出；接口成功、正文覆盖和机器评分各有定义 |
| 解析机器评分 | 文字/表格/顺序/公式字符串的标注分母分别为78/17/79/9；olmOCR断言分母125；公式字符串距离与公式字符检测匹配CDM（Character Detection Matching）是不同指标 |
| 解析扩展核验 | CDM执行0/8引擎，人工签名0/100页；本报告的质量比较使用已交付机器指标，人工评分与签名继续暂缓 |

| 定时工作流 | 默认分支已配置schedule，PR及workflow_dispatch执行证据按实际事件记录；截至交付证据观察时刻，首次schedule事件尚未观察 |

## 结果数据

- [原文问答逐题机器分数](data/reader-scores.json)：1200条，保留格式状态与人工字段空值。
- [Wiki逐对数据](data/wiki-pairs.json)：三批共90对，包含提示令牌、缓存读取令牌、费用和耗时。
- [八引擎解析结果](data/parser-results.json)：输入清单身份、预处理、状态及机器评分分母。
- [实验来源](data/experiment-provenance.json)：原文问答、完整检索实验、提示词与数据摘要；split字段为原始分区名称，样本为已观察公开子集。

解析数据采用原始结果中的评分及身份字段，完整数值保持一致。计费缺失保留未知值；模型质量、运行状态和成本分别统计。来源文件摘要列于[数据来源清单](data/sources.json)。
